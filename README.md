# TN Logistics & Services S.A.S. - Website

Una página web moderna, profesional y dinámica para TN Logistics & Services S.A.S., desarrollada con Astro, Tailwind CSS y GSAP ScrollTrigger.

## 🚀 Características

- **Diseño Moderno**: Interfaz limpia y profesional siguiendo la identidad corporativa
- **Animaciones Suaves**: Implementadas con GSAP ScrollTrigger para una experiencia fluida
- **Responsive**: Totalmente adaptable a todos los dispositivos
- **Optimizado**: Carga rápida y rendimiento optimizado con Astro
- **Accesible**: Cumple con estándares de accesibilidad web

## 📋 Secciones

1. **Hero Section** - Presentación principal con logo y eslogan animado

## 🚦 Instalación y Uso

### Prerrequisitos
- Node.js 18+ 
- npm o yarn

### Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Vista previa de producción
npm run preview
```

### Scripts Disponibles

- `npm run dev` - Servidor de desarrollo
- `npm run build` - Construir para producción
- `npm run preview` - Vista previa de la build

## ✨ Animaciones

### Tipos de Animaciones Implementadas
- **Fade In**: Aparición gradual de elementos
- **Slide Up**: Deslizamiento desde abajo
- **Stagger**: Animaciones escalonadas para listas
- **Hover Effects**: Efectos interactivos en botones y cards
- **Parallax**: Efectos de profundidad en backgrounds
- **Scroll Reveal**: Animaciones activadas por scroll

### Configuración GSAP
Las animaciones están configuradas en el layout principal y se activan automáticamente mediante clases CSS:
- `.animate-on-scroll` - Animación básica de scroll reveal
- `.stagger-item` - Elementos con animación escalonada
