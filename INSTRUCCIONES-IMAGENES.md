# 📸 Instrucciones para Agregar tus Propias Imágenes

## 📁 Ubicación de las Imágenes
Coloca tus imágenes en: `public/images/services/`

## 🖼️ Imágenes Necesarias (6 total)

### 1. **logistica-internacional.jpg**
- **Para:** Asesoría y Consultoría Logística
- **Sugerencia:** Puerto, contenedores, oficina logística, mapamundi
- **Tamaño recomendado:** 1920x1080px o superior
- **Formato:** JPG, PNG, WebP

### 2. **transporte-integral.jpg**
- **Para:** Servicios Logísticos Integrales  
- **Sugerencia:** Camiones, aviones de carga, barcos, cadena de suministro
- **Tamaño recomendado:** 1920x1080px o superior

### 3. **documentos-permisos.jpg**
- **Para:** Trámite de Vistos Buenos
- **Sugerencia:** Documentos, sellos, oficina gubernamental, papeleo
- **Tamaño recomendado:** 1920x1080px o superior

### 4. **planeacion-logistica.jpg**
- **Para:** Planeación Logística Integral
- **Sugerencia:** Gráficos, planificación, oficina moderna, análisis
- **Tamaño recomendado:** 1920x1080px o superior

### 5. **capacitacion-empresarial.jpg**
- **Para:** Capacitaciones Personalizadas
- **Sugerencia:** Sala de conferencias, presentación, equipo de trabajo
- **Tamaño recomendado:** 1920x1080px o superior

### 6. **china-comercial.jpg**
- **Para:** Asistencia Comercial en China

## ⚡ Optimización Recomendada
- **Peso máximo:** 500KB por imagen
- **Calidad:** 80-85% en JPG
- **Herramientas:** TinyPNG, Squoosh.app, Photoshop

## 🔄 Imágenes de Respaldo
Si no tienes alguna imagen lista, el sistema mostrará un color de fondo sólido hasta que agregues la imagen correspondiente.

## 🚀 Después de Agregar las Imágenes
1. Reinicia el servidor de desarrollo: `npm run dev`
2. Las imágenes aparecerán automáticamente en el banner
3. Cada imagen se mostrará cuando su servicio correspondiente esté activo
4. Las imágenes rotan automáticamente cada 4 segundos

## 📝 Nota Importante
- Las rutas son relativas a la carpeta `public/`
- No necesitas incluir `public/` en la ruta del código
- Ejemplo: `/images/services/logistica-internacional.jpg`
